# Basit – 3D Engine
Welcome to my second project on GitHub – my 3D Engine named Basit. In Arabic language, "basit" means "simple". So this project is SUPER SIMPLE.

## How to use this thing?
It's as simple as the project. There is a cube test in `main` function. Check it to understand how to make 3D shapes and other stuff.

btw you need SFML to run this thing.
